# AI質問機能 追加要望書 (`request.md`)

## 1. 概要

本プロジェクト（Express / TypeScript 製の既存Webアプリケーション）に、ユーザーからの質問を受け付け、AI（LLM）が回答を生成・返却する「AI質問機能」を追加する。既存のTODOアプリと同様のレイヤー構造を踏襲し、保守性と拡張性の高い設計で実装を行う。

---

## 2. 背景・目的

* **目的**: ユーザーがアプリケーション上で疑問点や質問を入力した際、AIが迅速に適切な回答を返す仕組みを提供し、アプリの利便性を向上させる。
* **対象ユーザー**: 本アプリを利用する一般ユーザーおよび管理者。

---

## 3. 要件定義

### 3.1. 機能要件

1. **AI質問画面（UI）の提供**
* ユーザーが質問を入力するための入力フォームと、AIからの回答を表示するエリアを持つ画面（またはTOP・TODO画面に統合するセクション）を提供する。


2. **質問送信とAI応答処理**
* ユーザーが入力した質問テキストをバックエンド（Expressサーバー）に送信する。
* サーバー側で外部AI API（例: OpenAI API等）を呼び出し、回答を取得してフロントエンドに返却する。


3. **エラーハンドリング**
* API通信エラーや入力値不正（空文字など）が発生した場合に、ユーザーフレンドリーなエラーメッセージを画面に表示する。
* サーバーがクラッシュしないよう、適切な例外処理とグローバルエラーハンドラーへの連携を行う。



### 3.2. 非機能要件

* **アーキテクチャの踏襲**:
* 既存の TODO アプリ（`src/apps/todo/`）の設計パターン（Router / Controller / Model・Service の分離）に倣い、AI機能用ディレクトリ（例: `src/apps/ai/`）を新設する。


* **セキュリティ・機密情報管理**:
* AIのAPIキー等の機密情報はソースコードに直書きせず、`dotenv` を利用して環境変数から安全に読み込むこと。


* **既存機能への影響ゼロ**:
* 既存のTODO機能、ルーティング、DB接続、404ハンドリング、エラーハンドリングを一切破壊しないこと。



---

## 4. 実装・配置スコープ案

### 4.1. 追加・修正予定のファイル

* **ルーティング**: `src/apps/ai/aiRouter.ts`
* **コントローラー**: `src/apps/ai/aiController.ts`
* **サービス/ロジック**: `src/apps/ai/aiService.ts` （AI API呼び出し等のビジネスロジック）
* **ビュー・静的ファイル**:
* `views/ai/index.ejs` （AI質問画面）
* `public/ai/ai.js` （フロントエンド用スクリプト）


* **サーバー統合**: `index.ts` にルーターのルーティング（例: `app.use('/ai', aiRouter)`）を追加。

### 4.2. 必要な外部パッケージ・環境変数

* **パッケージ追加（必要に応じて）**:
* AI SDK（例: `openai` または `@anthropic-ai/sdk` など、採用するLLMに合わせたクライアントライブラリ）


* **環境変数（追加）**:
* `AI_API_KEY` （または使用するAIサービスのAPIキー変数名）
